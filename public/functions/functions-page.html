Anything you need to know about functions.

Hoisting

JS reads documents with a "Just In Time" compilar - (JIT). This means that JS processes certain declarations before executing the code.

A function (and const and let aswell) can therefore be called before it appears in the code:


    getRandsomInt(5, 10)

    function getRandsomInt (min, max) {
        return Math.floor(Math.random() * (max - min + 1) + min);
    }

This works because the function is hoisted.

Random numbers

In the example before we saw the method .random(). In the function getRandsomInt we ask it to generate a random integer between min and max, including both.

Anonymous function

An "Anonymous function", is a function without a name


    // Example
    const getRandsomIntAnonymousFunction = function (min, max) {
        return Math.floor(Math.random() * (max - min + 1) + min);
    }

    // This function doesn't have a name
    function (min, max) { }

    // Instead it's stores in the variable
    const getRandomIntAnonymousFunction = ...

A more visual side-by-side example:


    // Function declaration
    const getRandomIntAnonymousFunction = ...

    function nonAnonymousFunction(min, max) {
        return Math.floor(Math.random() * (max - min + 1) + min);

    // Anonymous function
    const getRandsomIntAnonymousFunction = function (min, max) {
        return Math.floor(Math.random() * (max - min + 1) + min);

Functions as Arguments

JavaScript allows you to pass a function as an argument to another function.


    // Example:
    function genericActionPerformer(name, action) {
        return action(name);
    }

    // Task: Using the genericActionPerformer, can you make it say: Elias likes to play guitar 
    const name = "Elias";

    function playingGuitarAction (name) {
        return `${name} likes to play guitar`;
    }

    console.log(genericActionPerformer("Elias", playingGuitarAction));

    // Result prints: Elias likes to play guitar

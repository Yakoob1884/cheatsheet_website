Node REPL

Node REPL (Read-Eval-Print-Loop) allows you to write and execute JavaScript directly in the terminal. This tool is useful for quick testing and debugging.

How we run the JS:


    //In terminal 
        
        $  node <file-name>

    // This will run whatever code you have and show it in the terminal

Type coercion

Type coercion is the conversion of a value from one data type to another, likw a string becomes a number

To avoid this, use strict equality checks: === or !== whenever it's possible


    // Strict equality (=== or !== ) checks both the value and the data type
    // While equal (== !=) only checks the value.

Variables: const and let

The rule is to use const whenever possible, otherwise use let when you know the value needs to change.


    const myFavoriteNumber = 6
    // The number will stay const-ant 😜

    let age = 20
    age = 21
    // If we print age, it will now be 21 instead of the original value of 20

JavaScript objects

Objects store data using key-value pairs.

    // Example:

    const person = {
        name: "Morten"
    }

    // The key is name, and the value is Morten

You can also add properties after creating the object

    
    person.age = 69;

    // Now the object becomes:
    {
        name: "Morten",
        age: 69
    }

Node REPL

Node REPL (Read-Eval-Print-Loop) allows you to write and execute JavaScript directly in the terminal. This tool is useful for quick testing and debugging.

How we run the JS:


    //In terminal 
        
        $  node <file-name>

    // This will run whatever code you have and show it in the terminal

Type coercion

Type coercion is the conversion of a value from one data type to another, likw a string becomes a number

To avoid this, use strict equality checks: === or !== whenever it's possible


    // Strict equality (=== or !== ) checks both the value and the data type
    // While equal (== !=) only checks the value.

Variables: const and let

The rule is to use const whenever possible, otherwise use let when you know the value needs to change.


    const myFavoriteNumber = 6
    // The number will stay const-ant 😜

    let age = 20
    age = 21
    // If we print age, it will now be 21 instead of the original value of 20

JavaScript objects

Objects store data using key-value pairs.


    // Example:

    const person = {
        name: "Adam"
    }

    // The key is name, and the value is Adam

You can also add properties after creating the object

    
    person.age = 69

    // Now the object becomes:
    {
        name: "Adam",
        age: 69
    }

You can also delete properties again, by using delete person.name. Delete person does not delete the object.

Arrays

Arrays are used to store multiple values.

If we want to add an item to our array, we use .push().

                        
    // Example:
    const things = ["mouse"]

    things.push("car")

    // If we print things we will get the following result: ["mouse", "car"]

If we want to remove an item from our array, we use .pop()


    // Our array: ["mouse", "car"]
    
    things.pop()

    // If we print things we will get the following result: ["mouse"]

console.log()

Rule: Use comma in console.log when passing multiple values

We use commas to avoid concatenating values with "+", because "+" can trigger type coercion, and change the values.


    // Example:

    console.log(5 + 6)          // 11
    console.log("5" + "6")      // 56
    console.log(5, 6)           // 5 6
    console.log("5" , "6")      // 5 6

Strings

Strings can be written in many ways using:

Double quotes, single quotes or template literals, 


    // Example:
    const greeting = "Hello"
    const greeting = 'Hello'
    const greeting = `Hello`

    // Template literals also allow string interpolation using ${}
    const greeting = `Hello "${person.name}". This is the introduction class to Node.js`;

    // If person.name is "Adam", the result becomes:

Template literals can also be used for multi-line strings.

Strict Mode

With strict mode, you can't use undeclared variables. Strict mode is declared by adding "use strict" to the beginning of a script or a function.

If declared at the beginning of a script, it has global scope and all the code in the script will execute in strict mode

                        
    // Example:
    "use strict"
    totalGlobalVariables = "Never EVER do this" 

    // This causes an error because the variable was never declared

Some words cannot be used as variable names in certain contexts. public is a reserved keyword in strict-mode contexts and can cause an error.

Block scope

Any code wrapped in curly braces, like an if statements, for or while loops, or standalone blocks, is a block

Variables declared with let and const are block-scoped, while var behaves differently and is not block-scoped


    // Example:
    {
        var someValue = 123
        {
            var someValue = 456
        }
        console.log(someValue) // Prints 456
    }
                        

    // Example
    {
        let someOtherValue = true
        {
            let someOtherValue = false
        }
        console.log(someOtherValue) // Prints true
    }

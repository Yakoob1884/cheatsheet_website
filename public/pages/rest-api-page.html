Rules

Rule 1: Always use the right HTTP verbs

Rule 2: Always use the right order (GET, POST, PUT, PATCH, DELETE)

Rule 3: Always use nouns, and always make them plural

Since i'm currently on a plane, we are gonna use planecrashes lol

HTTP Method Endpoint Description
GET /planecrashes Retrieves all the crashes
GET /planecrashes/{id} Retrieves a crash by id
POST /planecrashes Creates a crash resource
PUT /planecrashes/{id} Replaces an entire crash resource
PATCH /planecrashes/{id} Replaces parts of the crash resource
DELETE /planecrashes/{id} Deletes a language resource

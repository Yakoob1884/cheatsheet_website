Everything you need to know about git and git bash

Add, commit, push

When we want to push our work to a repository, we fist want to add the work, commit the work, and push the work

                        
    // Example:
    $ git add -A        // Will add all the new changes
    $ git commit -m "Here you will write informative notes about the changes you have made"
    $ git push          // Now you have pushed your work for others to see

Clone

When you or a team member makes a repository, the easiest way to add the procjet (in my opinion) is by cloning the project

                        
    // Example:
    $ git clone <repository URL>

Branching

When working multiple people on the same repository, it is a good idea to be using branches, that way you avoid "bumbing into eachother". You can work on the same page and avoid merge issues.

This is personally my nemisis

                        
    // Example:
    $ git branch                          // When you wanna know what branch you are working from
    $ git checkout <branch-name>          // When you wanna move from branch to branch
    $ git checkout -b <branch-name>       // When you wanna make and move to a new branch
